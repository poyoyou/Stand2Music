# Stand2Song
a simple and funny program made with electron that gives the user a random jojo bizarre adventure stand, and then starts playing the music reference in the background.

for example, if u get Hey ya, the music "Hey ya!" from outkast will start playing in the background.

this project includes all the stands from part 3(stardust crusaders) to part 9 (jojolands) but some stands may not have a oficial music.
